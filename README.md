# Student Performance AI Analytics

**IBM SkillsBuild Data Analytics with AI Academic Internship Project**

## Project Description
This project analyzes student academic and lifestyle factors and uses a Random Forest model to predict final performance. It demonstrates data cleaning, EDA, visualization, correlation analysis, machine learning, evaluation, feature importance, and recommendation generation.

## Dataset
`student_performance_dataset.csv` — 250 synthetic records created for academic demonstration. No real student personal information is included.

## Technologies
Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

## Files
- `Vinit_Student_Performance_AI_Analytics.ipynb` — complete notebook
- `requirements.txt` — dependencies
- `README.md` — project information and setup
- `student_performance_dataset.csv` — dataset
- `Vinit_ProjectReport.docx` — project report

## Setup
```bash
pip install -r requirements.txt
jupyter notebook
```
Open the notebook and run the cells from top to bottom.

## Methodology
1. Data inspection and cleaning
2. Exploratory data analysis
3. Correlation and visualization
4. Feature preprocessing
5. Train/test split
6. Random Forest Regression
7. MAE, RMSE and R² evaluation
8. Feature importance
9. Recommendation generation

## Note
This project is for educational demonstration. Predictions should not be used as the sole basis for decisions about real students.
